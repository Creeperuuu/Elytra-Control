# Elytra Control

**Elytra Control** is a lightweight Minecraft mod that enhances your Elytra flight experience with more precise and customizable control options.

### ✨ Features:

* **Disable Fly** – Prevents Elytra flight entirely.
* **Cancel Fly** – Instantly cancels midair flight for smooth landings.
* **Easy Fly** – Makes Elytra takeoff easier and more accessible.

---

## 🖼️ Preview

Below are some visual previews of the mod in action.

### 🔒 Disable Fly

Completely disable Elytra flight when needed.
You can also customize the on-screen overlay:

* Icon only
* Text + Icon
* Text only
* Hidden (no overlay)

Additionally, you can adjust the overlay position anywhere on the screen.

![Disable Fly Preview](https://raw.githubusercontent.com/Smootheez/Elytra-Control/refs/heads/dev/assets/disable_elytra_preview.gif)

---

### 🛑 Cancel Fly

Cancel your Elytra flight midair by tapping the jump key—perfect for safe landings or quick stops.
Keybinds are fully customizable:

* Use the default jump behavior
* Or bind your own custom key

![Cancel Fly Preview](https://raw.githubusercontent.com/Smootheez/Elytra-Control/refs/heads/dev/assets/cancel_fly_action_preview.gif)

---

### 🚀 Easy Fly

Take off with Elytra more easily using this optional feature.
It's disabled by default, so you'll need to enable it via:

* The config menu (with `ModMenu` installed), or
* The config file in your `config` directory.

![Easy Fly Preview](https://raw.githubusercontent.com/Smootheez/Elytra-Control/refs/heads/dev/assets/easy_fly_action_preview.gif)

You can also assign keybinds to quickly toggle Easy Fly on or off.
Note: The keybind is unassigned by default—you'll need to bind it manually.

![Disable Easy Fly Preview](https://raw.githubusercontent.com/Smootheez/Elytra-Control/refs/heads/dev/assets/disable_easy_fly_preview.gif)

---

## ⚙️ Configuration

You can configure all features easily:

* In-game via the config menu *(requires ModMenu)*
* Manually by editing the config file
